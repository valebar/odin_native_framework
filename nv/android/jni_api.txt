# Java members the Android backend calls through JNI. android/jnigen turns this into
# nv/jni_api_android.odin (typed wrappers, descriptors verified with javap against android.jar and
# the nv shims). Format: `class member`, where member is `[return-type] name(type [name], ..)`,
# `<init>(..)` for a constructor, or `.field`; `= odin_name` overrides the derived name. The class
# is the *declaring* class (a method ID works on subclass instances). See android/jnigen/main.odin.
